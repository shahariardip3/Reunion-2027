# গঙ্গানন্দপুর মাধ্যমিক বিদ্যালয় — পুনর্মিলনী ২০২৭ (ওয়েবসাইট)

Next.js + Supabase। বাংলা/ইংরেজি, মোবাইল-ফার্স্ট, ডিফল্ট লাইট থিম (হেডারের 🌙 বাটনে ডার্ক থিম)।

## দ্রুত শুরু

বাংলা ধাপে ধাপে নির্দেশনা: `START-HERE-BN.md`। আগের Supabase project সচল থাকলে নতুন project তৈরি করার দরকার নেই।

## প্রথমে যা করতে হবে (সেভ/নোটিশ/নিবন্ধন কাজ না করার সমাধান)

নতুন Supabase প্রজেক্টে টেবিল বানালেও সার্ভার-কী (`service_role`)-কে টেবিলের **অনুমতি (GRANT)** দেওয়া হয় না। ফলে পড়া চুপচাপ ফাঁকা আসে আর সেভ/নোটিশ/নিবন্ধন ফেল করে। নতুন `supabase/schema.sql` এই অনুমতি দেয় এবং নতুন কলামও যোগ করে।

1. Supabase → **SQL Editor** → **New query**
2. `supabase/schema.sql`-এর **পুরোটা** পেস্ট করে **Run**
   - নতুন বা পুরোনো — দুই ক্ষেত্রেই চলবে, যতবার খুশি চালানো যায়, কোনো ডেটা মোছে না।
3. সাইট চালু করে `/admin` → **সিস্টেম চেক** ট্যাব খুলুন — সব ✅ হলে ঠিক আছে। কোনো ❌ থাকলে ঠিক কী করতে হবে সেখানেই লেখা আছে।

> `.env.local`-এ `SUPABASE_SERVICE_ROLE_KEY`-তে অবশ্যই **service_role** (বা নতুন `sb_secret_…`) কী দিন — **anon/publishable কী নয়**।

## কী কী নতুন

- **ডিজাইন:** হালকা (light) থিম, স্কুলের গেটের ছবি হেরো ব্যানার ও ব্যাকগ্রাউন্ডে, নরম অ্যানিমেশন, ডার্ক থিম বাটন।
- **নিবন্ধন ২ ধাপে:** ধাপ ১ তথ্য ও ছবি → ধাপ ২ পেমেন্ট (bKash / Nagad / ব্যাংক, কপি বাটনসহ)।
- **পেমেন্ট:** অ্যাডমিন সেটিংসে bKash ও Nagad-এর আলাদা নম্বর; **ব্যাংক তথ্য ঐচ্ছিক** (অ্যাকাউন্ট নম্বর না দিলে ব্যাংক অপশন দেখাবে না)। কোন মাধ্যমে পেমেন্ট হয়েছে তা অ্যাডমিন তালিকায় দেখা যায়।
- **SEO:** দুই ভাষার টাইটেল/ডেসক্রিপশন, কিওয়ার্ড, Open Graph (Facebook/WhatsApp প্রিভিউ), sitemap.xml, robots.txt, structured data (বিদ্যালয় + ইভেন্ট), canonical লিংক, স্কুল পরিচিতি ও FAQ সেকশন।
- **অ্যাডমিন:** সিস্টেম চেক ট্যাব, ত্রুটির আসল কোড/কারণ দেখায়।
- **অন্যান্য:** শেয়ার বাটন, ক্যালেন্ডারে যোগ (.ics), লাইভ কাউন্টডাউন, নিবন্ধন চালু/বন্ধ সুইচ, QR চেক-ইন (QR না চললে আইডি লিখে)।
- **সব ডিভাইসে:** Android, iPhone/iPad, Windows, Mac, Linux — পুরোনো ব্রাউজারের (Android ৫+ Chrome ৮০, iOS ১৩) জন্য কোড কম্পাইল, সব OS-এর বাংলা ফন্ট ফলব্যাক।

## বাটন কাজ না করলে (ভাষা / ডার্ক মোড / লগইন)
এর মানে ব্রাউজারে JavaScript চালু হয়নি। সমাধান:
1. পুরোনো ফোল্ডারের জায়গায় নতুন ফাইল বসানোর পর **`.next` ফোল্ডারটা মুছে দিন**, সার্ভার বন্ধ করে (`Ctrl+C`) আবার `npm run dev` দিন।
2. ব্রাউজারে জোর করে রিফ্রেশ করুন (`Ctrl+Shift+R`)।
3. ডেভ-মোডে এখন কোনো স্ক্রিপ্ট আটকে গেলে বা JS error হলে পেজের নিচে **লাল বার** দেখাবে — সেই লেখাটা পাঠান।
4. ফোন থেকে খুলতে চাইলে কম্পিউটার ও ফোন একই Wi-Fi-তে রেখে `http://কম্পিউটারের-IP:3000` ব্যবহার করুন।

## লোকালি চালানো
1. Node.js **20.9+** ইনস্টল করুন।
2. `.env.local.example` কপি করে `.env.local` নাম দিন এবং মান বসান (ভেতরে নির্দেশনা আছে)।
3. `npm install` → `npm run dev` → http://localhost:3000

## অ্যাডমিন (`/admin/login`)
- **নিবন্ধন:** টাকা যাচাই করে "অনুমোদন" → আইডি (REU-0001…) তৈরি।
- **QR চেক-ইন:** QR স্ক্যান বা রেজিস্ট্রেশন আইডি লিখে যাচাই → "উপস্থিত চিহ্নিত করুন"।
- **নোটিশ:** দুই ভাষায় লিখে প্রকাশ/খসড়া/পিন/মেয়াদ।
- **সেটিংস:** তারিখ, স্থান, ফি, bKash/Nagad নম্বর, ব্যাংক (ঐচ্ছিক), নিবন্ধন চালু/বন্ধ, Facebook।
- **সিস্টেম চেক:** ডাটাবেস/কী/অনুমতির সমস্যা ধরিয়ে দেয়।

## গুগলে ওয়েবসাইট আগে দেখানোর জন্য (SEO চেকলিস্ট)
কেউ গুগলে "১ নম্বরে" থাকার নিশ্চয়তা দিতে পারে না; তবে নিচের কাজগুলো করলে সবচেয়ে ভালো সুযোগ পাবেন:
1. ডিপ্লয়ের পর `SITE_URL` সেট করুন (যেমন `https://your-site.com`) এবং Redeploy করুন।
2. [Google Search Console](https://search.google.com/search-console) → Add property → ভেরিফাই করুন (HTML tag দিলে তার `content` মান `GOOGLE_SITE_VERIFICATION`-এ দিন)।
3. Search Console → **Sitemaps** → `sitemap.xml` সাবমিট করুন; **URL Inspection** দিয়ে হোমপেজে "Request indexing" দিন।
4. নিজের ডোমেইন (যেমন `ganganandapurreunion.com`) নিন — vercel.app সাবডোমেইনের চেয়ে ভালো।
5. স্কুলের Facebook Page, গ্রুপ ও অন্যান্য সাইট থেকে ওয়েবসাইটের লিংক দিন (ব্যাকলিংক)।
6. অ্যাডমিন সেটিংসে ইভেন্টের তারিখ, স্থান ও বিবরণ পূরণ রাখুন, নিয়মিত নোটিশ দিন।
7. গুগলে ইনডেক্স হতে সাধারণত কয়েক দিন থেকে কয়েক সপ্তাহ লাগে।
